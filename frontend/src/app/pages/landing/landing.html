Everything a modern team board needs

Four core capabilities built to keep teams moving without the busywork.

AI Card Generator

Claude API

Auto-detects task-shaped messages inside team chat and prompts for confirmation before a card is ever created.

Real-time Sync

Socket.io

Instant drag-and-drop board updates and comments — every teammate viewing the board sees the same state, live.

Smart Filtering

Saved filters

Save filter presets and use highlight groups to visually prioritize what matters most across a busy board.

Enterprise-grade RBAC

2-tier permissions

Organization-level and Board-level roles keep access scoped exactly to who should see and edit what.

AI Assistant

From conversation to card — automatically

Every board comes with a built-in team chat. The backend calls the Claude API to read each message, decide whether it reads like a task hand-off, and — only when you confirm — turn it into a real card.

  1. 1

    A message lands in chat

    "Need to fix the pagination bug on the board list before Friday."

  2. 2

    Claude extracts the task

    Title, assignee (matched by member name), and due date are pulled out via a fixed request/response contract.

  3. 3

    You confirm — nothing is silent

    The card only appears on the board after a human clicks confirm, so the board never fills up with noise.
